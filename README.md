## 💻 Projeto

<p align="left"> 
    <h3>Projeto desenvolvido para aprimorar habilidades em conexões com banco de dados e manipulação de dados. O sistema permite operações CRUD (criar e ler usuários por enquanto) utilizando PHP e MySQL. Para utilizar, clone o repositório, coloque na pasta htdocs do XAMPP e acesse via navegador. Ideal para estudos e práticas em desenvolvimento web. Contribuições são bem-vindas!</h3>
